========================================================================
🧠 AI COGNITIVE OS CLI (teZ.js) 移載與部署標準作業程序 (SOP_260701)
========================================================================

本文件說明如何將整合了 planA 工作流（Planner, Executor, Critic, Refiner, Sandbox, Embedding Memory）的
AI 認知系統命令列工具 (teZ.js) 移植、載入到任何新的乾淨環境中運行。

────────────────────────────────────────────────────────────────────────
一、 移載必備檔案清單 (Minimum Directory Structure)
────────────────────────────────────────────────────────────────────────
在移載至新目錄或新電腦時，您必須複製以下結構的檔案：

[您的目的目錄]/
├── teZ.js                   # 認知系統主程式
├── version.json             # 版本控制檔 (JSON 格式，由 VersionManager 讀寫)
├── config/
│   └── config.js            # 連線、模型名稱及輸出目錄等設定檔
└── core/
    └── version.js           # 版本升級與管理邏輯

*註：`memory/` (對話歷史與語意記憶) 目錄可選擇性複製。若不複製，新環境會自動初始化一個空的記憶檔。
*註：`Proj/` 與 `backup/` 目錄不需複製，執行時會自動建立。

────────────────────────────────────────────────────────────────────────
二、 系統環境與相依性準備
────────────────────────────────────────────────────────────────────────
1. 安裝 Node.js 環境：
   - 本工具採用 Node.js 原生 API 撰寫（不需執行 npm install 安裝第三方套件）。
   - 請至官網安裝 Node.js (v18 或更新版本)。
   - 原生模組相依性說明：
     - `readline` (互動 CLI 用)
     - `fs` (檔案操作與備份用)
     - `path` (路徑解析與移載相容性)
     - `crypto` (生成 UUID 用)
     - `child_process` (沙盒測試執行程式用)

2. 本地 AI 推理環境安裝與啟動 (Ollama)：
   - 請至 https://ollama.com 下載並安裝 Ollama。
   - 啟動 Ollama 服務（預設連接埠為 11434）。
   - 打開終端機下載本工具預設的模型：
     > ollama pull qwen2.5:3b
     > ollama pull qwen2.5:7b
   *註：若要使用其他模型，請至 `./config/config.js` 修改 `MODEL_FAST` 及 `MODEL_SMART` 設定。

────────────────────────────────────────────────────────────────────────
三、 新環境部署與執行步驟
────────────────────────────────────────────────────────────────────────
1. 將「第一節」清單中的檔案複製到您目標主機的新資料夾內（如：C:\AI-OS\ 或 /usr/local/ai-os/）。
2. 開啟終端機（cmd、PowerShell 或 bash），切換目錄至該資料夾：
   > cd [您的目的目錄路徑]
3. 啟動 Ollama 服務。
4. 執行啟動指令：
   > node teZ.js
5. 當看到「🧠 AI COGNITIVE OS v5 STARTED」且出現「You ➔」提示符號時，即代表系統移載與啟動成功。

────────────────────────────────────────────────────────────────────────
四、 常用功能指令說明書
────────────────────────────────────────────────────────────────────────
在「You ➔」提示符號後輸入以下指令可以發揮完整功能：

1. 一般提問 / 程式產生：
   - 直接輸入問題即可。若偵測到與「程式、Code、寫、實作」相關的關鍵字，會自動啟動 planA 工作流程：
     Planner -> Executor -> Critic -> Refiner/Validator Loop -> 自動儲存與 Sandbox 執行檢測。

2. 檔案分析與修改 (/file)：
   - 語法：`/file <檔案相對/絕對路徑> [選填指示詞]`
   - 範例：`/file Proj/main.js 幫我重構這個檔案，並把重複代碼抽離`

3. 專案/資料夾分析 (/folder)：
   - 語法：`/folder <相對/絕對路徑>`
   - 範例：`/folder ./src`
   - 功能：自動掃描並載入整個資料夾（過濾無關檔案如 node_modules），整理出結構樹與全部內容餵給 AI。

4. 程式碼還原 (/rollback)：
   - 語法：`/rollback <Proj資料夾下的檔名>`
   - 範例：`/rollback main.js`
   - 功能：將檔案還原到最新一份的備份檔狀態（每次 AI 改寫前皆會於 backup/ 生成備份）。

5. 模型動態切換 (/model)：
   - 語法：`/model [fast | smart | dynamic]`
   - 範例：`/model smart` (鎖定使用高品質模型)

6. 系統檢查與控制：
   - `/check`  : 運行功能檢查清單。
   - `/runtime`: 顯示運行狀態監控（運作時間、記憶圖節點數、獎勵積分等）。
   - `/bump`   : 手動為專案升級版本號。
   - `/clear`  : 清除圖形記憶與語意向量庫。
   - `/help`   : 顯示指令協助。
   - `exit`    : 安全結束程式。
