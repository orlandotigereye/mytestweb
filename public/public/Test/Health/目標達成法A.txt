最終大方向（頂層目標）
├── 財富與人心的複利投資系統
│   ├── 核心規律：用大腦自己的機制對抗大腦弱點
│   │   ├── 微小行動 + 立即情緒獎勵 + 證據累積 + 外部鎖定 = 必然自動化
│   │   ├── 身份轉換是最強槓桿（證據越多，舊身份越崩解）
│   │   └── 系統設計 > 意志力（路徑阻力最小 → 行為必然發生）
│   ├── 應用層：投資（金融資產）與人心（關係/忠誠/上癮）
│   │   ├── 金融：風險降低 + 成功率提升 → 財富複利
│   │   └── 人心：每日微證據 + 情緒強化 + 群組證明 → 忠誠/上癮複利
│   └── 長期成果：行為自動化（基底核60–90天）→ 偏誤減弱 → 理性決策 → 自由
│
├── 神經層面基礎（大腦機制）
│   ├── 杏仁核（amygdala）：虧損厭惡、情緒恐懼 → 損失痛苦 ≈ 獲利快樂的2倍
│   ├── 基底核（basal ganglia）：習慣自動化 → 每天微行動重複 → 無意識執行
│   ├── 腹內側前額葉（vmPFC）：價值編碼 → 虧損區陡峭、獲利區平緩
│   ├── 背外側前額葉（dlPFC）：系統2理性控制 → 過度自信時活性降低
│   ├── 背側前扣帶回（dACC）：錯誤監控 → 過度自信時減弱 → ERN波形變小
│   └── 紋狀體 / VTA：多巴胺獎勵 → 從眾、慶祝、社會證明時爆發
│
├── 偏誤識別與實時預測（日常觀察層）
│   ├── 情緒極端（sentiment extreme）：AAII >60%看多 / VIX >40 → 預測反轉
│   ├── 敘事峰值/崩解（narrative peak/collapse）：媒體熱度極值 + 反敘事興起 → 淡出/進場
│   ├── 拋物線 + 價差擴大（parabolic + spread widening）：流動性真空 → 減倉
│   ├── 投降量能（capitulation volume）：低量凍結 → 突發大量下殺 → 潛在底部
│   └── 日常小信號（生理/語言）：急著決定（快語、出汗）、絕對語（這次不一樣）、從眾心癢、沉沒成本胸悶
│
├── 啟動與執行工具層（微習慣系統）
│   ├── 5-Second Rule：倒數 → 立即身體行動 → 中斷系統1衝動
│   ├── Tiny Habit 三要素：錨點 + 微行動 + 慶祝（多巴胺黏合劑）
│   │   ├── Minimum + Stretch：最小版不可能失敗 + 延伸版滿足成就感
│   │   ├── Never Miss Twice：絕不連續錯過兩次（防火牆）
│   │   └── Disaster Plan：極小版（觸碰App、寫一字）在混亂日存活
│   ├── 誘惑捆綁 + 習慣堆疊：該做 + 想做配對 → 任務變享受
│   └── 每日30秒神經自查：情緒？錨定？系統1/2？ → 抓到異常即調整
│
└── 長期強化與排除障礙層（系統穩定器）
    ├── 身份強化：每天「我做了X，這證明我是…」 + 證據日誌
    ├── 外部壓力：公開承諾、罰款、群組證明 → 放棄更痛苦
    ├── 高原期應對：努力型（加新奇）、成果型（加延伸）、身份型（加證據）
    ├── 閃亮物症候群：Idea Jail（30天等待）+ Parking Lot + 每週審核
    └── 每季大慶祝：90天里程碑 → 強化長期動能
