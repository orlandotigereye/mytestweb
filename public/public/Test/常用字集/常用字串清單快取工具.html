支援公開 Google Sheet 試算表 ID / 網址（CSV 匯出）或 Google Apps Script Web App 網址，設定自動儲存於瀏覽器 localStorage。

建議欄位順序（第 1 列為標題）： 名稱 / 標籤, 字串內容 / 密碼, 分類（選填）, 備註（選填）

若您的試算表設為私人或含敏感密碼，建議使用 Google Apps Script Web App（回傳 JSON 陣列或 CSV）搭配存取控管，並於同步失敗時自動保留內建/快取清單。
